## 3. កាតព្វកិច្ចរបស់អតិថិជន៖ ការត្រួតពិនិត្យនៅពេលទំនិញមកដល់

អតិថិជន **ត្រូវតែ** ត្រួតពិនិត្យទំនិញនៅពេលមកដល់។ នេះជាលក្ខខណ្ឌចាំបាច់ ដើម្បីរក្សាសិទ្ធិទាមទារពេញលេញ។ ការត្រួតពិនិត្យមាន 5 ជំហាន៖

1. **រាប់ចំនួន** — រាប់ដុំ / សន្លឹក / m³ ឱ្យត្រូវនឹងលិខិតបញ្ជូន មុនពេលឡានចេញ។
2. **វាស់វិមាត្រ** — វាស់កម្រាស់ ប្រវែង ទទឹង ដោយប្រើម៉ែត្រ ឬកាលីប។
3. **ពិនិត្យរូបរាង** — មើលថាតើមានសន្លឹកបាក់ ខូច រលាយ ឬខូចទ្រង់ទ្រាយឬទេ។
4. **ផ្ទៀងផ្ទាត់ដង់ស៊ីតេ និងលេខកូដដុំ** — ប្រៀបធៀបជាមួយលិខិតបញ្ជូន។
5. **ថតរូប និងចុះហត្ថលេខា** — ថតរូបទំនិញ និងលិខិតបញ្ជូន រួចចុះហត្ថលេខាទទួល។

សូមកត់សម្គាល់៖ បើអតិថិជនចុះហត្ថលេខាទទួលដោយគ្មានការកត់ត្រាបញ្ហា ហើយក្រោយមកទាមទារការខូចខាតផ្នែករូបរាង ការទាមទារនោះអាចមិនត្រូវបានទទួលយក ព្រោះមិនអាចបញ្ជាក់បានថាការខូចខាតកើតឡើងមុន ឬក្រោយពេលដឹក។ ដូច្នេះ សូមកត់ត្រាបញ្ហានៅលើលិខិតបញ្ជូនភ្លាមៗនៅពេលរកឃើញ។
