## ១. សេចក្តីថ្លែងការណ៍គោលដែលត្រូវនិយាយឲ្យត្រូវ

**EPS ស្តង់ដារអាចឆេះបាន (combustible)។ វាមិនមែនជាសម្ភារៈមិនឆេះទេ ហើយមិនត្រូវអះអាងថាមិនឆេះឡើយ។**

ការពិតដែលត្រូវប្រាប់អតិថិជនឲ្យច្បាស់៖
- **ថ្នាក់ស្តង់ដារ (standard grade) គឺអាចឆេះបាន** និងអាចឆេះបន្តពេលមានប្រភពភ្លើងគ្រប់គ្រាន់
- **ថ្នាក់ FR (flame-retardant) grade មានជូនតាមការស្នើសុំ** — ត្រូវបញ្ជាក់ **នៅពេលបញ្ជាទិញ**
- **ក្រុមហ៊ុនមិនអាចបន្ថែម FR ក្រោយពេលផលិតរួច ឬក្រោយពេលដឹកជញ្ជូនបានទេ**
- សម្រាប់អគារដែលមានមនុស្សរស់នៅ ឬធ្វើការ **EPS ត្រូវការពារដោយស្រទាប់បិទបាំង (facing/covering) ដែលបានអនុម័ត**
- ការប្រើប្រាស់នៅកន្លែងដែលមានតម្រូវការអគ្គិសនី ឬភ្លើងខ្ពស់ ត្រូវពិគ្រោះជាមួយវិស្វករ និងអាជ្ញាធរមានសមត្ថកិច្ច

**ហេតុអ្វីត្រូវប្រុងប្រយ័ត្នក្នុងការនិយាយ៖** ការអះអាងខុសថា EPS "មិនឆេះ" គឺជាកំហុសធ្ងន់ធ្ងរ ដែលអាចនាំឲ្យមានគ្រោះថ្នាក់ដល់អាយុជីវិត និងបញ្ហាច្បាប់។ ត្រូវនិយាយថា **"អាចឆេះបាន តែអាចកាត់បន្ថយហានិភ័យបានតាមការរចនា និងការប្រើ FR grade"**។

## ២. ថ្នាក់ FR (flame-retardant) ធ្វើអ្វី និងមិនធ្វើអ្វី

### អ្វីដែល FR ធ្វើ

FR គឺជាសារធាតុបន្ថែម (additive) ដែលដាក់ចូលក្នុងគ្រាប់ EPS ក្នុងពេលផលិត។ វាធ្វើឲ្យ៖
- **កាត់បន្ថយលទ្ធភាពឆេះបន្ត** — ពេលដកប្រភពភ្លើងចេញ សម្ភារៈមានទំនោររលត់ដោយខ្លួនឯងជាងមិនរលត់
- **បន្ថយល្បឿននៃការឆេះរាលដាល** តាមផ្ទៃ
- **បន្ថយការបន្តឆេះពេលប៉ះអណ្តាតភ្លើងតូច** (ឧទាហរណ៍ ផ្កាភ្លើងដែនាំ)

### អ្វីដែល FR មិនធ្វើ

- **មិនធ្វើឲ្យ EPS ក្លាយជាសម្ភារៈមិនឆេះ (non-combustible)**
- **មិនទប់ទល់ភ្លើងធំ** ឬភ្លើងដែលមានប្រភពកម្ដៅខ្លាំងបន្ត
- **មិនជំនួសតម្រូវការស្រទាប់បិទបាំង (facing)** ក្នុងអគារដែលមានមនុស្ស
- **មិនជំនួសវិធានការសុវត្ថិភាពផ្សេងទៀត** ដូចជា ការរក្សាចម្ងាយពីកម្ដៅ ការគ្រប់គ្រងការងារក្តៅ និងប្រព័ន្ធពន្លត់ភ្លើង
- **មិនទប់ស្កាត់ការបញ្ចេញផ្សែង** ពេលឆេះ

**សេចក្តីសន្និដ្ឋាន៖** FR ជាវិធានការ **កាត់បន្ថយហានិភ័យ** មិនមែនជាការធានាសុវត្ថិភាពដាច់ខាតទេ។ ត្រូវពន្យល់អតិថិជនតាមនេះ។

## ៣. ការផ្ទុក និងការដោះស្រាយឲ្យបានត្រឹមត្រូវ

### ច្បាប់ផ្ទុក

| ច្បាប់ | ហេតុផល |
|---|---|
| **ក្នុងម្លប់ (shade)** | ពន្លឺព្រះអាទិត្យផ្ទាល់ធ្វើឲ្យ EPS លឿង ប្រែពណ៌ និងខូចផ្ទៃ |
| **លើជើងទម្រ (off the ground)** | ការពារសំណើមពីដី និងការជ្រាបទឹក |
| **ឆ្ងាយពីអណ្តាតភ្លើង (away from open flame)** | បន្ថយហានិភ័យការបញ្ឆេះ |
| **ឆ្ងាយពីសារធាតុរំលាយ និងប្រេងឥន្ធនៈ** | សារធាតុទាំងនេះ **រំលាយ EPS** និងបង្កើតហានិភ័យភ្លើង |
| **គ្មានការជក់បារី (no smoking)** | ការពារផ្កាភ្លើង និងកម្ដៅពីការជក់បារី |
| **មិនទុកក្នុងភ្លៀងយូរ** | ទឹកជ្រាបចូលចន្លោះសន្លឹក ធ្វើឲ្យខូច និងថយអ៊ីសូឡង់ |
| **ការបញ្ចេញខ្យល់ចេញចូលល្អ** | ជៀសវាងការកកកុញចំហាយ pentane ក្នុងកន្លែងបិទជិត |
| **ជៀសវាងការសង្កត់ធ្ងន់លើស** | បន្ទះខាងក្រោមអាចរលំ ឬខូចរាង |

### សារធាតុដែលត្រូវជៀសវាងដាច់ខាត

EPS ត្រូវបាន **រំលាយ** ដោយសារធាតុរំលាយសរីរាង្គ។ ត្រូវរក្សាចម្ងាយពី៖
- សារធាតុរំលាយដូចជា អាសេតូន ថិនណឺ និងសារធាតុរំលាយថ្នាំលាប
- ប្រេងឥន្ធនៈ ប្រេងសាំង ប្រេងម៉ាស៊ីន និងសារធាតុរំលាយឧស្សាហកម្ម
- កាវ និងថ្នាំកាវដែលមានសារធាតុរំលាយខ្លាំង
- សារធាតុអុកស៊ីតកម្មខ្លាំង

**ការខូចដោយសារធាតុទាំងនេះមិនស្ថិតក្រោមការធានាទេ។** យោងតាមលក្ខខណ្ឌរបស់ក្រុមហ៊ុន ការខូចដោយការផ្ទុកមិនត្រឹមត្រូវ (ពន្លឺព្រះអាទិត្យផ្ទាល់ ភ្លៀងយូរ ប៉ះសារធាតុរំលាយ ឬប្រេងឥន្ធនៈ) **មិនត្រូវបានគ្របដណ្តប់** ដោយការធានា។

### ការដឹកជញ្ជូន

- គ្របសន្លឹកដោយសំណាញ់ ឬផ្ទាំងក្រណាត់ពេលដឹកក្នុងពន្លឺថ្ងៃ
- មិនដាក់ជិតបំពង់ផ្សែងឡាន ឬប្រភពកម្ដៅ
- ចងឲ្យជាប់ តែមិនសង្កត់ខ្លាំងពេក ដើម្បីកុំឲ្យខូចគែម
- ពេលដឹកជាមួយប្រេង ឬសារធាតុរំលាយ ត្រូវបែងចែកឲ្យដាច់ដោយឡែក

## ៤. ការអនុវត្តសុវត្ថិភាពក្នុងការដំឡើង

### វិធានការជុំវិញការងារក្តៅ (hot works)

ការងារក្តៅ គឺជាមូលហេតុចម្បងនៃអគ្គិភ័យក្នុងការដំឡើង EPS។ ត្រូវអនុវត្តយ៉ាងតឹងរ៉ឹង៖

- **ដក EPS ចេញពីតំបន់ការងារក្តៅ** មុនពេលផ្សារ កាត់ដែក ឬប្រើឧបករណ៍បង្កើតផ្កាភ្លើង
- បើមិនអាចដកចេញបាន ត្រូវ **គ្របដោយផ្ទាំងការពារមិនឆេះ** ដូចជា ផ្ទាំងដែក ឬផ្ទាំង fire blanket
- **មានឧបករណ៍ពន្លត់ភ្លើងនៅកន្លែងការងារ** ជានិច្ច និងមានមនុស្សម្នាក់ឃ្លាំមើល
