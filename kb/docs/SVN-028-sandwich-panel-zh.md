## 一、产品说明

**EPS-P（EPS Sandwich Panel，ផ្ទាំងសាំងវិច EPS，彩钢夹芯板 / EPS夹芯板）** 是万方建材（WANFANG INSULATION PACKAGING MATERIAL CO., LTD）在柬埔寨茶胶省（Takeo province）工厂生产的**复合保温板材**：以 EPS 为芯材，上下两面复合面板，经粘结、加压、定尺切割而成。它是"保温层 + 面层 + 结构面"三合一的产品——一面墙或一块屋面板，一次安装即同时完成保温、饰面与围护，比"龙骨 + 填充保温棉 + 封板"的传统做法节省人工与工期。

- **计价单位：按 KG 与按 m² 双轨计价**
- **锚定价格：$2.80 / KG**
- **芯材：EPS，密度按订单确认（一般 10–20 kg/m³）**
- **芯材厚度：50 / 75 / 100 / 150 / 200 mm**
- **板宽：950 / 1000 / 1150 mm；长度：最大 6000 mm**
- 使用温度范围：**−40 °C 至 +70 °C**（短期可达 80 °C）
- 阻燃性：标准级为可燃材料；**FR（阻燃）级可按需定制，必须在下单时明确注明**。

## 二、板材构造

EPS-P 夹芯板由三层构成：

| 层次 | 材料 | 作用 |
|---|---|---|
| 上面板（外/内视安装方向） | 彩涂钢板、纤维水泥板、铝箔或石膏板 | 承力、饰面、防潮、耐候 |
| 芯材 | EPS（可发性聚苯乙烯） | 保温隔热、隔声、减轻自重 |
| 下面板 | 同上，可与上面板不同材质 | 承力、饰面、封闭芯材 |

**构造要点**

- EPS 芯材为闭孔结构，导热系数低（10 kg/m³ 时 λ = 0.038 W/(m·K)，20 kg/m³ 时 λ = 0.033 W/(m·K)），因此薄板即可获得较好保温效果。
- 板边通常做成插接（公母槽）或平口形式，拼装后形成连续保温面；板缝必须打胶密封，否则冷库或空调房会在缝隙处结露。
- 面板与芯材之间采用粘结复合，不得有脱层、空鼓；板面应平整、无明显波浪。
- EPS 芯材为**可燃材料**；用于有防火要求的部位时，须在下单时注明 **FR 阻燃级**，事后无法追加阻燃性能。

**关于板宽的选择**

- **950 mm**：较窄，适合小面积隔断、门洞周边、需频繁搬运的场合。
- **1000 mm**：通用宽度，覆盖面积与施工效率平衡最好，最常用。
- **1150 mm**：最宽，减少拼缝数量，适合大面积墙面与屋面，但对运输与吊装要求更高。

**关于长度的选择**

- 定尺长度可减少现场切割与拼缝，是提高防水与气密性的关键。建议按墙面或屋面实际尺寸定尺，**最长 6000 mm**。
- 超过 6000 mm 的整面墙体需分段拼接，拼缝处必须打耐候密封胶，并加设檩条或龙骨支撑。

| 面板类型 | 厚度规格 | 特点 | 典型用途 |
|---|---|---|---|
| 彩涂钢板 | **0.326 / 0.376 / 0.426 mm** | 强度高、耐候、颜色可选、易清洁 | 厂房墙面与屋面、冷库外墙、洁净间 |
| 纤维水泥板 | 按订单确认 | 防火性能好、表面可涂装、质感偏硬 | 有防火要求的隔断、外墙内衬 |
| 铝箔 | 按订单确认 | 反射辐射热、防潮隔汽、重量轻 | 冷库内衬、空调房、管道保温贴面 |
| 石膏板 | 按订单确认 | 室内饰面效果好、易批灰涂装 | 室内隔墙、办公室、洁净间内墙 |

**钢板厚度如何选**

- **0.326 mm**：经济型，适用于室内隔断、非承重内墙。
- **0.376 mm**：通用型，适用于厂房墙面、冷库墙体、屋面板。
- **0.426 mm**：加强型，适用于大跨度屋面、外墙、风荷载较大区域与需承受检修人流的屋面。

**注意**：彩涂钢板表面涂层在运输与安装中易被划伤，切割产生的铁屑须及时清除，否则会锈蚀板面。安装完成后应撕除保护膜（如有），避免长期暴晒后胶残留。

## 七、选型指南（按应用场景）

### 7.1 隔断墙（厂房内隔断、办公室隔断）

- **推荐厚度：50 mm 或 75 mm**
- **推荐面板：彩涂钢板 0.326 / 0.376 mm，或石膏板（室内饰面）**
- **参考价：50 mm → $9.80 / m²；75 mm → $12.60 / m²**
- 要点：隔断以轻量与快速安装为目标，50 mm 已能满足一般隔声与隔热；对隔声要求高的房间（如空压机房）建议 75 mm 并做双层板或填缝处理。顶天立地的隔断需设置顶部与底部收边件。

### 7.2 屋面（厂房、仓库、雨棚）

- **推荐厚度：75 mm 或 100 mm**
- **推荐面板：彩涂钢板 0.376 / 0.426 mm（外板加强）**
- **参考价：75 mm → $12.60 / m²；100 mm → $15.40 / m²**
- 要点：屋面板需承受风荷载、检修人流与热带暴雨，建议外板用 0.426 mm；板长尽量定尺到屋面整跨长度（最大 6000 mm），减少搭接；坡度建议不小于 5%，搭接处打耐候胶并采用顺水搭接方向；紧固件须带防水垫圈。

### 7.3 冷库墙体与顶板

- **推荐厚度：冷藏库（chiller）100 mm；冷冻库（freezer）150 mm；速冻库（blast freezer）200 mm**
- **推荐面板：彩涂钢板（库内侧可用不锈钢或铝箔贴面）**
- **推荐芯材密度：20–30 kg/m³**
- **参考价：100 mm → $15.40 / m²；150 mm → $20.80 / m²；200 mm → $26.50 / m²**
- 要点：冷库板缝必须连续密封，转角、门洞、管道穿孔处均需专用收边与密封件；地面与墙体交接处应设置防潮隔汽层并延伸至墙面；库内不得使用可燃保温材料而未做防火隔离。使用温度范围 −40 °C 至 +70 °C 完全覆盖常规冷冻与速冻工况。

### 7.4 洁净间（食品、电子、医药车间）

- **推荐厚度：50 mm 或 75 mm**
- **推荐面板：彩涂钢板（表面平整、易清洁、不产尘）或石膏板 + 涂装**
- **参考价：50 mm → $9.80 / m²；75 mm → $12.60 / m²**
- 要点：洁净间关注的是**气密性与表面平整度**而非保温厚度；所有板缝、阴阳角、门窗框周边须用中性硅酮胶或专用密封件处理；墙面与地面交接建议做圆弧收边，便于冲洗；如需防火分隔，请注明 **FR 阻燃级**。

### 7.5 其他应用

- **空调车间 / 恒温仓库**：75–100 mm，减少冷量损失。
- **活动房 / 临时办公**：50 mm，兼顾轻量与隔热。
- **设备罩壳 / 隔声罩**：50 mm，配合吸声处理。
